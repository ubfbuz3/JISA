## Problem Anchor

变形测试（Metamorphic Testing）已成为 Web 系统安全 oracle 的主流方案。其中
**MST-wi（IEEE TSE 2023）** 给出了 76 条系统无关 MR，在 Jenkins/Joomla 上报告
敏感度 85%、特异性 99.81%，且工具与复现包完全公开。其 MR 目录中包含利用
CWE-639（"Authorization Bypass Through User-Controlled Key" = BOLA 的标准 CWE 定义）
的授权类 MR，并声称可以缓解安全测试的 oracle problem。

**锚定的问题**：这些授权类 MR 在 BOLA 判定上的能力**边界**在哪里？
它在哪里失效？失效可否量化？可否修正？

## Dominant Contribution

**刻画并证明 MR 例外语言在对象级授权上的表达力边界，给出越过该边界的可执行机制。**

三层合法例外：

| 层级 | 形式 | 元数 | MST-wi 的 DSL 谓词 | 可表达 |
|---|---|---|---|---|
| **E1** 主体属性 | `f(i)` | 1（主体） | `isAdmin(user)` | ✅ |
| **E2** 主体间关系 | `g(i, u_A)` | 2（主体, 主体） | `isSupervisorOf(u1, u2)` | ✅ |
| **E3** 主体×对象显式授权 | `h(i, o)` | 2（主体, **对象**） | **无（零命中）** | ❌ |

**不可表达性命题**：把 E3 条件 `h(i,o)` 作为 precondition 加入 MR，则
`h(i,o) ≡ P(i,o,read)`，其中 `P` 正是 BOLA 判定所要确定的政策谓词本身；
于是 MR 退化为 `¬P(i,o) ∧ … → 应拒绝`，即"若无权则无权"——重言式，检出力为零。∎

> 可证伪条件：若能给出 MST-wi 目录中任一可表达 E3 的谓词，命题即被推翻。
> 已穷举其谓词全集（v5 §1.2），未发现。（`userCanRetrieveContent` 看似相关，
> 但它判定的是**运行时实际取到了什么**，而非**政策是否授权**。）

## Method: Boundary-aware MR Execution

给 MR 触发加一个**对象级 E3 探测**步骤，把二值报告升级为三级裁决：

| 步骤 | 操作 |
|---|---|
| 1 | 执行 MR。未触发 → `pass` |
| 2 | 触发 → **探测 E3**：该对象自创建以来是否被显式共享/委派？ |
| 3 | E3 存在且权限覆盖本次操作 → `indeterminate` + 输出见证（共享记录）<br>E3 不存在或权限不覆盖 → `violation-proven` |

**为什么探测不循环**（这是 v4 想立但未能形式化的那一步）：
E3 探测读取的是**测试框架自己调用共享 API 时写下的记录**，是
**构造式真值（constructive ground truth）**，而不是"从实现制品推断出的政策"。

两个版本（用于简洁性检查）：

- **v1**：仅**存在性**探测 —— 对象有任意共享记录即降级
- **v2**：存在性 + **权限层级匹配** —— 共享记录的 `permission` 必须覆盖触发动作的
  操作类型（`read` 覆盖读；`write` 覆盖读与写）。v2 用于消除"读合法 / 写越权"场景的
  误降级代价。

## 预期结果表（预注册，来自 v5 §2.4）

| 场景 | MR 触发 | 真实情况 | 原 MR 判定 | Boundary-aware 判定 |
|---|---|---|---|---|
| 无共享 + 正常 | 否 | 正常 | TN ✅ | TN ✅ |
| 无共享 + 越权 | 是 | BOLA | TP ✅ | `violation-proven` ✅ |
| **有共享 + 正常** | **是** | **正常** | **FP ❌** | **`indeterminate` ✅** |
| 有共享 + 越权 | 是 | BOLA | TP ⚠️（与上不可区分） | `violation-proven`（E3 被排除） |

## 明确不声称

- ❌ 不声称提出新 MR（本工作不新增 MR 目录）
- ❌ 不声称"发现更多漏洞"或数值上优越于 MST-wi
- ❌ 不声称 MST-wi 有错（其结论在其语料 Jenkins/Joomla 上成立）
- ❌ 不声称能判定所有 BOLA
- ❌ 不声称使用 LLM 环节（本方法**不含** LLM；判定全部由确定性规则完成）
