# 实验设计：claim → 证据 → 运行顺序

> 生成：2026-09-18 · 结构依 ARIS `experiment-agent` / `experiment-plan` 的 claim-driven 路线图，内容**全部绑定已落盘的真实运行记录**
> 原则：**每个 claim 必须绑定一个可复算的证据源**；无证据的 claim 直接删除，不写成"未来工作"。

---

## 0. 论文故事线（一段话）

MST-wi 用 76 条系统无关的变形关系把 Web 安全测试从 oracle problem 里救出来，并以 **specificity 99.81%** 立论。
本文证明：**这些关系在对象级授权上的判定被外包给了一个"GUI 可达性模型"**，而该模型是**采集期快照**。
于是当授权**在采集之后以带外方式产生**时，模型与真实授权状态分离，判定沿**确定性的方向**失真——
不是随机误报，而是**把合法的带外访问升级为 `violation-proven`**（本文称「假确证」）。
我们给出该失效的**三条边界**——有可读 oracle 时 MR 可被普通请求替代；无 oracle 时 MR 退化为 GUI 代理；
已报 specificity 以「GUI 模型 ≡ 真实授权状态」为未声明前提——并在真实系统（Gitea 1.22.6）上复现了时序失配与 oracle 的权限门控。

## 2. 实验台与场景（合成矩阵）

| 场景 | 构造 | 真值 | 作用 |
|---|---|---|---|
| S1 | 无共享，跨用户访问同一对象 | normal | 阴性对照（基线 FP） |
| S2 | 无共享，跨用户访问 | bola（vuln=1） | 检出侧阳性 |
| S3 | **框架**调用共享 API 建的共享 → 合法跨账户访问 | normal | FP_E3 主锚点 |
| S4 | 未共享对象上的访问 | bola/normal | 对照 |
| S5 | 只读共享下的**写**越权 | bola | 辨析力探针 |
| **S6** | **带外**预存共享（管理员配置 / 历史委派）→ 合法 | normal | ★ 可观测性边界 |
| **S7** | 带外预存 + **真越权** | bola | 边界的**单侧性**检验 |

**配置轴（析因设计，非随机抽样）**：
- `mode ∈ {e3, noe3}`：SUT 是否具备对象级共享能力
- `vulnerable ∈ {0, 1}`：SUT 是否存在授权缺陷
- `share_visibility ∈ {listed, unlisted}`：共享对是否在 GUI 列举中出现
- **`introspection ∈ {on, off}`**：SUT 是否暴露可读的授权自省面
- `precond_variant ∈ {raw, e1, e1e2}`：例外谓词层级 ℒ₁/ℒ₂ 消融
- `gui_mode ∈ {aware, blind}`：前置条件是否依赖 GUI 可达性

**规模**：8 配置 × 7 场景 × 2 MR × variants = **576 条记录，0 错误**。
**代表切片** = `precond=raw ∧ gui_mode=aware`（最忠实 MST-wi 原始行为的设定）。

> ⚠️ 必须声明：这是**析因设计**，不是"真实系统抽样"。所有"发生率"类结论**只能**来自 §4 的实例无关系数。

## 8. 新颖性隔离（本文最大的短板，须直说）

**FINER 中 Novel 是唯一下拉项**（第 5–7 轮一致）。原因不是"被人占满"，而是：

> **"提出机制"这条路被本文自己的数据关闭**——`v3` 在 oracle 可读时被一次普通请求**点估计不劣**地替代（C4）。
> ⇒ 凡"我的新组件是必要的"这类主张，**必须先跑"去掉该组件、用最朴素替代物"的对照组**，
> 且对照组必须**消费与真值同源的可观测量**，否则是稻草人（`direct_only` 的教训）。

**唯一能抬升 Novel 的动作 = N3（野外发生率）**，且它**不能靠多跑受控实验替代**。
