\section{Three boundaries, confirmed at source, and executed}
\label{sec:boundaries}

\subsection{Boundary 1 (RQ1): deterministic false proofs as designed}

\emph{Taken as published---raw alarms, or alarms filtered by bookkeeping
exceptions---the adjudication reports a legitimate access granted out of band
after the crawl as an already-established violation, in one direction.} On the
constructed system, rate \ResObsOobVtwoFpRate{} (\ResObsOobVtwoFalseProof{} of
\ResObsOobFalseAlarm{} alarms) against \ResObsFwVtwoFalseProof{} for the same
share created in band; on Gitea, \ResRsMrBookkeepingFp{} false proofs on
\ResRsAuthorizedCells{} authorized cells (\ResRsMrBookkeepingFpRate{}) under the
crawl-time reading, against \ResRsMrBookkeepingAlarmsLive{} alarms live---the
error is a property of the \emph{reading}, not of the system. The direction is
forced: the predicate has exactly two representations, and a grant created
outside the crawled interface has no representation but ``cannot reach''. The
predecessor attributes its residual false alarms to crawler
coverage~\cite{Mai2019Metamorphic}; we add that the failure is a function of
\emph{when} the model was read, which is what makes the Boundary-2 repair
available---and empty.

\subsection{Boundary 2 (RQ2): with a sound, readable oracle, the metamorphic step provides no additional detection benefit}

\emph{If the false proofs of Boundary~1 are removed by consulting a readable
introspection surface, it is the oracle that carries the work: for the
authorization relations and scenarios evaluated here, replacing the entire
metamorphic step with a single ordinary request---one that consumes the same
readable oracle and access outcome---provides no additional measurable detection
benefit.} Evidence: Table~\ref{tab:ablation}---\ResAbDirectObserveFP{} false
proofs vs.~\ResAbVThreeFP{} (a tie at zero, not a win), recall
\ResAbDirectObserveRec{} vs.~\ResAbVThreeRec{}, difference \ResAbRecallDiff{},
95\% CI $[\ResAbRecallDiffLo{}, \ResAbRecallDiffHi{}]$---descriptive, not a
test; no margin was fixed in advance. Gitea independently reproduces the
zero-false-proof result (\ResRsDirectObserveFp{} vs.~\ResRsVThreeFp{}), but does
not provide a recall comparison because the tested surface contains no seeded
vulnerability. Two qualifications are part of the claim: the surviving
difference is on recall alone, and there the MR-based method fails on all
\ResAbDisagreementN{} disagreements; and the control is \emph{constructed}, not
discovered---\texttt{direct\_observe} consumes definitionally the quantities
that define the ground truth, so the comparison is a statement about the
definitions: when the same sound authorization oracle and access outcome are
available, the metamorphic step provides no additional adjudication information.

\subsection{Boundary 3 (RQ3): the reported specificity rests on an undeclared premise and a low-resolution denominator}

\emph{The reported \ResLitReportedSpecPct{}\% is a statement about a corpus of
generated inputs under the assumption that the reachability model coincides with
the true authorization state.} The premise: adjudication is a function of the
reachability model, so where model and true state diverge---the out-of-band case
of Boundary~1---the figure measures agreement with the tool's own crawler; the
authors concede the mapping is ``not always
available''~\cite{Chaleshtari2022Metamorphic}, but the number is reported
without the condition. The denominator: a failure uniform across a scenario
class contributes only as many false positives as that class emits inputs, and
is diluted by the rest of the run (Proposition below). We are not saying the
figure is false or the false positives misdiagnosed; the claim is that such a
metric cannot discharge its own premise nor see a class-uniform failure.

\subsection{Implementation-level confirmation}
\label{sec:impl}

Definitions can be read generously, so we checked the predicates at source in
the public library~\cite{Chaleshtari2022Metamorphic}. It ships \ResArtMrTotal{}
relations, \ResArtAuthzMrTotal{} authorization relations,
\ResArtAuthzGatedEither{} gating on the two predicates analysed. Four
implementation-level properties not made explicit in the main presentation:
(i)~\emph{the freeze is hard-coded}---%
\texttt{cannotReachThroughGUI} is set-membership over the crawl inputs, issues
no request, and is cached in a field written once and never invalidated
(\texttt{userCanRetrieveContent} likewise reads a crawl-produced store loaded
once); (ii)~\emph{the clause that could have caught it is inert}---the
``absent across all users'' set is built by stopping each recorded sequence at
the first login action, so it is always empty; (iii)~\emph{missing data defaults
to an alarm}---with an empty or null crawl argument the predicate returns
``cannot reach'', so an empty crawl \emph{satisfies} the precondition: the
mechanism behind Boundary~1's deterministic direction; (iv)~\emph{the role
relation is configuration, not state}---the supervisor guard reads a static
configuration file and reports true for identical accounts, so it cannot reflect
a later grant.

\subsection{Executing the published relations}
\label{sec:native-run}

The library ships relations but no execution environment; we supplied the system
configuration and crawl snapshot and ran the relations---source unmodified,
build configuration (\texttt{pom.xml}) and an external harness added
(\NtUpstreamModified{} changed upstream file, \NtUpstreamJavaModified{} changed
Java sources, two added classes totalling \NtHarnessLines{} lines)---against
Gitea \NtGiteaVersion{} (Table~\ref{tab:native-facts}). \NtMrExecuted{} of \NtMrTotal{} authorization relations

engine's own \texttt{getFailures()} value (Table~\ref{tab:native}). Almost none
of the \NtElapsedS{} seconds is analysis: each leaf evaluation invokes a
browser-cleanup hook costing minutes, a cost of the missing environment that
bounds any reproduction.

\subsection{Admissibility, and falsification}
\label{sec:admissibility}

An adjudicator may promote a verdict to \texttt{violation-proven} on a readable
introspection surface only when (1)~the surface is readable and (2)~one can give
a reason that it is not of the same kind as the defect under test---not itself a
reachability artefact whose blind spot correlates with the blindness tested.
Clause~2 is a per-system judgement and not automatable; the cross-vendor results
make it concrete (Gogs and GitLab fail it; their adjudicators convert the blind
spots into \GgFpVthree{} and \GlFpVthree{} false proofs). Where the condition
holds, the honest method consumes the oracle directly and drops the relation;
where it does not, the honest method abstains---as v3 does on the unreadable
stratum, where the aggregate table would have ranked it best, a ranking that
reflects abstention rather than improved detection. Each boundary would fall as
follows: Boundary~1, if the predicates were defined over live rather than
recorded reachability; Boundary~2, by an authorization MR needing an observable
that a succeeding request plus a readable oracle cannot produce; Boundary~3, by
a specificity in scenario units, or with the premise explicit, that still fails
to separate the configurations studied here.
