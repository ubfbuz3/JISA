\subsection{What pooling hid: the ablation split by oracle readability}
\label{sec:stratum}

Table~\ref{tab:ablation} pools two populations in which the oracle-consuming methods behave in
opposite ways. The records differ in one respect that decides whether those methods can act at
all: whether the introspection surface returns a reading. We therefore repeat the same comparison
inside each stratum (Table~\ref{tab:stratum}), with the same methods and decision rule, and add two
references that need no oracle.

\paragraph{Reconciling the representative grid with this partition}
The 36/18 grid of Section~\ref{sec:synthetic} is a single point of the switch space, not a
miniature of the full partition. Table~\ref{tab:reconcile} closes the gap additively and record by
record: the two other exception policies add \DsgStepPvN{}, the blind reading \DsgStepGuiN{},
S1--S2 \DsgStepSXN{}, and the two no-exception configurations \DsgStepNoeThreeN{}, all unreadable.
The blocks are disjoint and their union is the full \DsgRecords{} records; the readable count runs
\DsgGridOn{} $\rightarrow$ \DsgBaseTwoOn{} $\rightarrow$ \DsgAllSwOn{} $\rightarrow$
\DsgEthreeOn{} $\rightarrow$ \DsgFullOn{}.

\paragraph{Stratification variable} We stratify on the \emph{effective} readability of the
surface---the value the probe returns---not on the configuration switch:
\MiiFlagOnButUnavailable{} records sit in configurations flagged \texttt{introspection=on} whose
surface nevertheless returns nothing. The two strata partition all \MiiNTotal{} records:
\MiiNOn{} readable, \MiiNOff{} unreadable.

\paragraph{The readable stratum strengthens Finding~2}
Splitting does not rescue the metamorphic step; it removes the comparison in which it looked
best. On the \MiiNOn{} readable records \texttt{direct\_observe} reaches recall
\MiiOnDirectObserveRec{} with \MiiOnDirectObserveFP{} false proofs, against v2's \MiiOnVTwoRec{}
with \MiiOnVTwoFP{} and v3's \MiiOnVThreeRec{} with \MiiOnVThreeFP{}. The plain request is ahead
on false proofs and not behind on detections, whereas the pooled table had let the family appear
competitive. The comparison rests on Proposition~\ref{lem:oracle-suff}, and
\texttt{direct\_observe} is not an independent method here, being built from the same two
quantities that define the reference.

\paragraph{The unreadable stratum is the relation's own regime, and it is not empty}
The \MiiNOff{} unreadable records contain \MiiOffNBola{} true violations and \MiiOffNNormal{}
correct cases, a base rate of \MiiOffPrevalencePct{}\%. Every oracle-bearing method detects none
of them (\MiiOffVThreeTP{}), because those methods have nothing to consult and abstain. The
metamorphic family does not: v2 reaches all \MiiOffVTwoTP{} true violations (recall
\MiiOffVTwoRec{}) with \MiiOffVTwoFP{} false proofs at precision \MiiOffVTwoPrec{}, a lift of
\MiiLiftVTwo{}$\times$ over the base rate. \texttt{always\_alarm} scores the base rate itself
(\MiiOffAlwaysAlarmPrec{}); \texttt{obs\_success} reaches the \emph{same} recall at precision
\MiiOffObsSuccessPrec{}, lift \MiiLiftObsSuccess{}$\times$. The net difference is therefore not in
detections (\MiiDeltaTPVTwoMinusObsSuccess{} additional true violations) but in false alarms:
\MiiOffAttribSavedFPTotal{} fewer for the metamorphic family.

\paragraph{What the saving consists of}
The attribution is one-sided and mechanical. Every record of the \MiiOffAttribSavedFPTotal{}-alarm
saving falls on S3, the legitimate share created \emph{through the framework's own facility}:
\MiiOffScenThreeObsSuccessFP{} false alarms for \texttt{obs\_success} against
\MiiOffScenThreeVTwoFP{} for v2 on the \MiiOffScenThreeN{} records of that scenario. On S6, the
same share created out of band, the two agree exactly (\MiiOffScenSixObsSuccessFP{}
vs.\ \MiiOffScenSixVTwoFP{}), for the reason developed in Section~\ref{sec:boundary1}. The
incremental detection information the metamorphic step carries where no oracle exists is
therefore exactly the information the crawl-derived model can see: it suppresses what was logged,
and reproduces Finding~1 on what was not. That bounds Finding~2 rather than overturning it. Both
references are deliberately weak and share an observable with the reference labelling, so only
the differences are meant to be read.
